Jak podpiąć swoją grę

  1. Weź od ziomka plik gamestate_integration_cscoach.cfg (jest w nim token drużyny, nie wrzucaj go nigdzie publicznie).
  2. Wrzuć go do folderu
    Steam\steamapps\common\Counter-Strike Global Offensive\game\csgo\cfg\
    Najszybciej: Steam → CS2 → prawy klik → Zarządzaj → Przeglądaj pliki lokalne → game\csgo\cfg.
  3. Uruchom CS2 ponownie (gra czyta ten plik tylko przy starcie).
  4. Graj. Po rozgrzewce mecz pojawi się tutaj, a na górze zobaczysz, kto gra teraz.

To oficjalne Game State Integration od Valve: gra sama wysyła stan meczu. Nic nie czyta pamięci gry, więc VAC i Faceit AC nie mają się do czego przyczepić. Dane dotyczą tylko twojego gracza: twoje kille, dmg, kasa, wynik i czas rund.
